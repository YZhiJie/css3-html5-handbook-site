高频语法速查表 ​

与 docs/ 深度文档配套的速查手册：每个主题只保留最常用的语法模板与结论，开发中快速定位用。深入原理请进入对应文档。

CSS 速查 ​

1. 高级选择器 ​

css
/* 属性选择器 */
[href^="https"]   { }  /* 以 https 开头 */
[href$=".pdf"]    { }  /* 以 .pdf 结尾 */
[class*="btn"]    { }  /* 包含 btn */
[data-state~="active"] { } /* 含独立单词 active */

/* 结构伪类：nth 公式（an+b），奇偶可用 odd/even */
li:nth-child(3n + 1) { }
li:nth-last-child(-n + 3) { }   /* 最后三个 */

/* 逻辑组合：is 取最高优先级，where 恒为 0，has 向上选择父级 */
:is(h1, h2, h3) { }
:where(article p) { margin-block: 0; }
.card:has(img) { padding: 0; }          /* 含 img 的卡片 */
li:has(+ li) { margin-bottom: 8px; }    /* 后面还有兄弟的项 */

/* 伪元素 */
.icon::before { content: "→"; }
input::placeholder { color: #999; }

2. 动画与过渡 ​

css
/* 过渡：property duration timing-function delay */
.btn { transition: transform .3s cubic-bezier(.22,1,.36,1), opacity .2s; }
.btn:hover { transform: translateY(-2px); }

/* 关键帧动画 */
@keyframes slide-in {
  from { opacity: 0; transform: translateX(-20px); }
  to   { opacity: 1; transform: none; }
}
.tip { animation: slide-in .4s ease-out both; }
.tip.paused { animation-play-state: paused; }

/* 性能三原则：只动 transform / opacity；长列表用 IntersectionObserver 触发；
   尊重系统减弱动态偏好 */
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}

4. GPU 合成 ​

想做什么怎么写注意
位移动画transform: translateX()不触发布局/绘制
淡入淡出opacity常被自动提升
提前提升will-change: transform动画前加、结束后撤
3D/层深translateZ(0) / perspective滥用会层爆炸
限制重排范围contain: layout paint明确隔离边界
长列表屏外跳过content-visibility: auto配 contain-intrinsic-size
text
层显存 ≈ CSS 宽 × 高 × DPR² × 4 字节（实际再上浮 30%~100%）
  • 只动画 transform / opacity；left/top/width/height 会击穿 Layout。
  • will-change 是手术刀：只给持续动画的元素，动画结束移除。
  • filter / backdrop-filter / 大模糊 / mix-blend-mode 很贵，优先减少面积与层数。
  • 用 DevTools：Layers 面板看层数，Rendering → Layer borders / Paint flashing / Frame Rendering Stats。

5. 主线程与长任务 ​

js
// 任务切片：优先 scheduler.yield，回退 MessageChannel
async function chunked(total, step, work) {
  for (let i = 0; i < total; i += step) {
    work(i, Math.min(i + step, total));
    if ('scheduler' in window && scheduler.yield) await scheduler.yield();
    else await new Promise((r) => setTimeout(r, 0));
  }
}
// 长任务观测（Chromium）
new PerformanceObserver((l) => {
  for (const e of l.getEntries()) console.log('longtask', e.startTime, e.duration);
}).observe({ type: 'longtask', buffered: true });
  • 单任务 > 50ms 即长任务；帧预算 16.7ms。
  • 读写分离：先批量读（getBoundingClientRect），再批量写，避免 layout thrashing。
  • 重计算进 Web Worker；大列表用虚拟滚动；输入用防抖/节流 + yield 让出主线程。
  • requestIdleCallback 只适合可延迟的后台工作，不适合关键交互。

6. 缓存与资源 ​

资源推荐策略
HTMLCache-Control: no-cache（每次协商）
带 hash 的 JS/CSS/图片Cache-Control: public, max-age=31536000, immutable
API 可容忍短暂旧数据stale-while-revalidate=60
用户私有数据private, no-store（按合规要求）
js
// SW：静态 cache-first，导航 network-first，API stale-while-revalidate
self.addEventListener('fetch', (e) => {
  const req = e.request;
  if (req.destination === 'document') {
    e.respondWith(fetch(req).catch(() => caches.match('/offline.html')));
  } else if (req.url.includes('/api/')) {
    e.respondWith((async () => {
      const cache = await caches.open('api-v1');
      const hit = await cache.match(req);
      const net = fetch(req).then((r) => { cache.put(req, r.clone()); return r; });
      return hit || net;
    })());
  } else {
    e.respondWith(caches.match(req).then((hit) => hit || fetch(req)));
  }
});
  • 发版后旧缓存清理：缓存名带版本号，activate 时删除非当前版本。
  • 压缩：Brotli 优于 gzip；图片优先 AVIF/WebP；字体子集化。
  • 资源提示：preconnect ≤3~4 个关键域；preload 只放当前页确定用的资源（字体带 crossorigin）。
