2 · Service Worker 三策略动画对比

假设静态资源已预热。观察三种策略在“请求 → 缓存/网络 → 返回 → 更新”上的耗时差异；重复点击会先清掉上一轮定时器。

Cache First

待运行
1. 拦截 fetch 请求
2. caches.match 命中
3. 直接返回缓存
4. 未命中时才走网络
返回耗时：—

Network First

待运行
1. 拦截 fetch 请求
2. 先发网络请求
3. 200 返回并写缓存
4. 失败/超时才回退缓存
返回耗时：—

Stale While Revalidate

待运行
1. 命中缓存立即返回
2. 页面先拿到旧数据
3. 后台发起网络更新
4. 下次访问拿到新数据
返回耗时：—

结论：Cache First 最适合带 hash 的静态资源；Network First 适合 HTML/API；SWR 用“一次旧数据”换取稳定秒开。
