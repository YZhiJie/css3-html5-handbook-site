② 合成层开关 + 层检查器（模拟显存账本）

③ 绘制成本：backdrop-filter / filter: blur / mix-blend-mode

filter 把元素画进离屏缓冲再做卷积；backdrop-filter 还要读取"背后已经画好的内容"， 背景一动就每帧重算；mix-blend-mode 需要背景像素参与混合。光斑在动时切换模式，看 FPS 与掉帧。

④ DevTools 操作指引（把"看不见的层"量出来）

Layers 面板
  • More tools → Layers
  • 查看层树、层尺寸、内存估算
  • "Why this layer?" 显示成层原因
  • 点击层可在页面高亮
Rendering 面板
  • Layer borders：给每个合成层画框
  • Paint flashing：绿色闪烁 = 发生重绘
  • Frame Rendering Stats：实时 FPS / GPU 内存
  • CPU Throttling：4×/6× 模拟低端机
Performance 面板
  • 录制一次动画，看是否有 Layout / Paint 条
  • 只有 Composite 说明已交给合成器
  • 对比"开销"与"帧率"，别只看平均 FPS
