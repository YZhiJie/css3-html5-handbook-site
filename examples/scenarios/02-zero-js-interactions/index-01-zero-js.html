② :has() · 父级感知后代状态

输入框使用 :user-invalid，只有用户交互后才判红；父级 .field:has(:user-invalid) 同步改变边框与提示，无需 JS 切类名。

③ 能力边界

popover不维护 aria-expanded，严格无障碍场景仍需少量 JS 同步； 锚点定位仍在跨引擎推进，示例在 Chrome 125+ 体验最佳； @starting-style只影响首次渲染帧，关闭动画需要 allow-discrete。
