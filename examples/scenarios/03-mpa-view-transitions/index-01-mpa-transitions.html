包含块与 BFC

绝对定位的参照系不是“最近的有定位的元素”这么简单：transform、filter、contain:paint 都会创建包含块。动画一加，布局契约就可能被改写。

② Speculation Rules 配置

<script type="speculationrules">
{
  "prerender": [
    { "where": { "href_matches": "/articles/*" },
      "eagerness": "moderate" }
  ],
  "prefetch": [
    { "where": { "href_matches": "/docs/*" },
      "eagerness": "conservative" }
  ]
}
</script>
等待模拟…

预取把网络等待提前到用户犹豫时；命中时导航可省 100–300ms。 eagerness 越高命中率越高，但会消耗更多流量与 CPU。
