💡 tailwind-merge 的冲突检测规则

  • ✅ 相同 CSS 属性的工具类 → 后者赢
  • ✅ 同一工具类族（flex-* / rounded-* / bg-*）→ 后者赢
  • ✅ 综合属性覆盖分向属性（p-8 覆盖 px-4 py-2）
  • ✅ 只有 前缀相同 的才会互相冲突（hover:bg-* vs bg-* 不冲突）
  • ❌ clsx 完全不做冲突检测，只拼接
