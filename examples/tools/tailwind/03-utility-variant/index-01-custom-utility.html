🛠️ Tailwind v4 @utility & @variant 实战

这个文件没有任何外部 JS 插件——所有扩展都是纯 CSS at-rule 写的。 双击 HTML 文件即可运行。

1. @utility 定义 text-shadow 系列

text-shadow-sm — 细小阴影

text-shadow-md — 中等阴影

text-shadow-lg — 大阴影

/* 在 CSS 的 @import 之后定义 */
@utility text-shadow-sm { text-shadow: 0 1px 2px rgba(0,0,0,0.1); }
@utility text-shadow-md { text-shadow: 0 2px 4px rgba(0,0,0,0.15); }
@utility text-shadow-lg { text-shadow: 0 4px 8px rgba(0,0,0,0.2); }

2. @utility gradient-text — 彩虹渐变文字

Hello Tailwind v4 ✨

这是一个自定义工具类，一次性实现渐变背景 + clip-text + transparent。

@utility gradient-text {
  background-image: linear-gradient(to right, #6366f1, #8b5cf6, #d946ef, #ec4899);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}

3. @variant fancy — 自定义前缀 

@variant fancy {
  &:hover {
    transform: scale(1.05);
    transition: transform 0.2s ease-out;
  }
}

/* 用法：fancy 是一个"变体"，里面定义了 hover 条件 + 属性 */
/* 直接写 fancy 即可触发 */
<button class="bg-blue-500 text-white px-4 py-2 rounded fancy">

4. 组合：fancy + 响应式 + dark

💡 工具类 + 响应式前缀 + 伪状态 + dark + 自定义 @variant fancy + 任意变体 [&:hover]:rounded-full —— v4 里一切都可以自由组合。

@utility subtle-glow {
  box-shadow:
    0 0 0 1px rgba(0,0,0,0.05),   /* 细微边框 */
    0 1px 2px rgba(0,0,0,0.05),    /* 紧贴投影 */
    0 4px 12px rgba(0,0,0,0.08);   /* 柔和光晕 */
}

💡 @variant vs @utility

@utility = 一条/一组 CSS 属性（"是什么"）；
@variant = 什么时候生效（"在什么条件下"）。

两者可以组合：fancy:bg-blue-500 读作"当 fancy 条件满足时，应用 bg-blue-500 这个工具类"。
