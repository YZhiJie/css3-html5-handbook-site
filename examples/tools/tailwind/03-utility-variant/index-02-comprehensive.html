1. @utility 做按钮组件

Primary 按钮（不同尺寸）

Outline / Ghost 变体

叠加响应式前缀

/* 每个 @utility 单独定义，组合使用 */
@utility btn-base { display: inline-flex; align-items: center; gap: 0.5rem; ... }
@utility btn-sm   { padding: 0.25rem 0.75rem; font-size: 0.875rem; }
@utility btn-md   { padding: 0.5rem 1rem;     font-size: 0.875rem; }
@utility btn-lg   { padding: 0.75rem 1.5rem;  font-size: 1rem; }
@utility btn-primary { background-color: blue; color: white; }
/* HTML 里像搭积木一样组合 */
<button class="btn-base btn-sm btn-primary">OK</button>

2. @variant 自定义前缀

selected 变体（点按钮切换选中状态）

selected:bg-blue-500 selected:text-white

keyboard-focus 变体（按 Tab 观察）

💡 用 focus-visible 实现： 鼠标点击不显示焦点环，键盘 Tab 才显示

tiny 变体（≤479px 时才生效，比 sm 还小）

当前视口宽度：—px ≤479px 时背景变粉色 
/* selector 形式：匹配 aria-selected 属性 */
@variant selected { &[aria-selected="true"]; }

/* selector 形式：键盘 focus */
@variant keyboard-focus { &:focus-visible; }

/* @media 形式：小屏 */
@variant tiny { @media (max-width: 479px); }

3. @source —— 告诉 Tailwind 去哪里找类名

v4 在 Vite/Next 里默认扫描 src 目录。但如果你有 Django 模板、Go views、或在 Play CDN 里引用外部文件，需要用 @source 指定扫描路径。 

@import "tailwindcss";

/* 扫描 Django 模板 */
@source "../../templates/**/*.html";

/* 扫描 legacy 代码 */
@source "../legacy/**/*.{jinja,twig}";

/* 排除 node_modules（默认已排除，显式写更清晰） */
@source "../**/*.html" exclude "../../../node_modules/**";

@theme {
  --color-brand: #da373d;
}

@utility text-shadow-sm { text-shadow: 0 1px 2px rgba(0,0,0,0.1); }

💡 @source 的路径是相对于当前 CSS 文件位置的。
