快速开始 ​

所有示例均为单文件 HTML，双击即可运行：

bash
# 在线阅读本站即可；本地启动文档站
npm install
npm run docs:dev

需要本地服务器的特例（均在示例文件头部注明）：

  • 06-web-workers：已采用 Blob 内联 Worker，双击即可运行；多文件写法需 http-server 等静态服务。
  • 07-geolocation：浏览器要求 https 或 localhost，示例提供 Mock 模式演示。
  • 09-multimedia：本地音视频文件建议通过 localhost 访问以避免自动播放策略限制。
  • 13-speculation-rules：prerender/prefetch 需 http://localhost 或 https，file:// 双击不生效。

推荐阅读顺序 ​

  1. 打牢布局基础 → Flexbox、Grid、响应式设计
  2. 掌握现代选择器与层叠 → 高级选择器、层叠层、:has() 选择器
  3. 玩转动效 → 动画与过渡、滚动驱动动画、View Transitions
  4. 进阶 HTML 平台能力 → Popover、dialog 元素、Observer 三件套、Web Components
  5. 建立性能工程体系 → Web Vitals 与性能度量、首屏加载与白屏治理、GPU 合成与渲染性能、主线程与长任务治理、资源与缓存策略、性能审计与监控
  6. 补齐渲染机制 → 渲染管线、包含块与格式化上下文、强制同步布局、合成层与 GPU 加速、渲染时序
  7. 组合场景实战 → 组件级响应式、零 JS 交互组件、MPA 级转场
  8. 搭建架构体系 → 设计令牌的分层与落地、cascade layers 与 @scope、主题与明暗体系、Tailwind 与原生 CSS 的边界
  9. 建立质量门禁 → 视觉回归测试、可访问性审计、性能预算与 CI 门禁、兼容矩阵与渐进增强兜底
  10. 实战查漏补缺 → CSS/HTML 反例库、分级自测题库
